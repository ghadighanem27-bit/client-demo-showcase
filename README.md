# Le Cèdre — Gastronomic Restaurant (Showcase)

A modern, fully responsive web interface designed and developed as a proof of concept (POC) for **Le Cèdre**, a fine-dining Lebanese restaurant located in Nice, France. 

**🔗 [Live Demonstration](https://demo-le-cedre.netlify.app/)**

> **Note:** This repository serves as a technical showcase. The live demonstration is configured to prevent search engine indexing (`noindex`) in order to protect the conceptual nature of this project.

## 🎯 Project Overview

This project aims to deliver a premium digital experience reflecting the restaurant's high-end positioning (Michelin Selection 2026, Maître Restaurateur, Grand Cordon d'Or). The focus was on front-end performance, elegant UI/UX design, and fluid navigation across all devices.

### ✨ Key Features
*   **Premium UI/UX:** Elegant typography (Cinzel, Playfair Display, Cormorant Garamond) and a refined layout that matches the gastronomic identity.
*   **Responsive Design:** Fully adapted for mobile, tablet, and desktop viewing, including a custom mobile navigation dialog and quick-action buttons (Call/Maps).
*   **Performance Optimization:** Implementation of WebP images, preloaded fonts, and a lightweight DOM structure for fast loading times.
*   **Social Proof Integration:** Dedicated sections highlighting Google Reviews (4.8/5) and TheFork ratings (9.6/10).
*   **Infinite Scroll Banner:** A seamless CSS animation showcasing the restaurant's culinary distinctions and awards.
*   **Multi-Page Routing:** Structured navigation including Home (`/`), Menu (`/carte`), and The Concept (`/concept`).

## 💻 Tech Stack

*   **Front-end:** HTML5, Modern CSS (Variables, Flexbox/Grid, Custom Animations), Vanilla JavaScript
*   **Assets:** Optimized WebP imagery, Google Fonts
*   **Hosting & Deployment:** Netlify (Continuous Deployment)
